# ASTRAEON original art

Generated for this game project and optimized as WebP for the browser.

- `astral-outpost.webp`: painted Astral Gate environment used on character creation.
- `hero-atlas.webp`: 4 × 4 character animation atlas: idle, run, sword combo, and dodge.
- `astral-wolf.webp`: 4 × 4 spectral wolf animation atlas: idle, stalk, attack, and hit.
