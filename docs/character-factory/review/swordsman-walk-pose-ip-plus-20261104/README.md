# Swordsman Walk SW: IP-Adapter Plus study

**Rejected, single frame only.** [Result](result.png). The generated face is obscured, and the armor, clothing, proportions and weapon differ from the protected Swordsman design. A single pose provides no evidence of animation continuity, grip, foot contact, cutouts or runtime quality. Do not use this image as production art or extend it to the other frames.

The CPU experiment used the protected baseline image encoded with IP-Adapter Plus hidden states, DreamShaper 8 and the OpenPose guide, with seed 20261104, strength 0.20, 20 steps and both conditioning scales 1.0. Model revisions, input and output hashes and actual run time are in the [receipt](../../../../authoring/characters/factory-v3/patch-0.0.1/research/swordsman-walk-pose-ip-plus-20261104/receipt.json); the reference embedding and its provenance are stored alongside it. The reference is from the approved tall Swordsman source, not a new character design. The full setup and source-model licensing are described in the earlier [CPU study](../swordsman-walk-pose-ipadapter-20261104/README.md). `ASTRA_IP_ADAPTER_FILE=ip-adapter-plus_sd15.safetensors` selects Plus in the setup script. The setup has not been run end-to-end from an empty environment, and this particular image has not been rerun for exact reproduction.

This result is not a finished action and does not change playable coverage. Further retries of single-image diffusion do not establish the per-frame painted master required by the plan; evaluate a method that preserves identity, geometry and motion across the complete sequence before expanding it.
