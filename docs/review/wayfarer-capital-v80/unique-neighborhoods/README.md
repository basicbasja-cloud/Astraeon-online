# Original occupied neighborhoods, v80

User priority: genuinely different houses, natural tree placement, and controlled
aligned/staggered frontage within a royal capital. RO3's supplied local beta
frames are a hard visual target, while Astraeon owns all models and artwork.

Four original structural designs replace selected upper assemblies on twelve
new houses: tall/low stepped wings, a long garden cottage with a dormer, a broken
merchant gambrel with real dormer openings, and an octagonal glazed corner oriel.
Ground entries, actual uses, retained low shelters and collision cores remain.
These are structural silhouette changes rather than four texture skins.

Ten small garden trees use actual planted-ground contacts, unequal spacing,
varied height and rotation, with both rounded and upright crowns. Existing royal
avenue/parterre planting remains formal. Do not scatter tilted houses or trees
randomly; owned yards, frontage, routes and entrances determine placement.

This includes recovered v79 planted-property work: 280m² of added green,
168 sparse three-blade edge tufts, sixteen formal crown variants, a full-size
1254² original painted foliage image, warmer clay, and the reviewed ordinary
camera baseline (45° pitch,35° yaw,135 distance,FOV15).

Independent geometry preservation, native source parity, full4096 floor-shadow
bakes, exact streaming, ordinary gameplay captures/culling, camera controls,
mobile emulation, offline/cache and field return must pass before checkpoint
acceptance. Physical iPhone Safari remains pending until a device is available.
