# Original full-body attack blocking study

Eight authored keys over 800 ms, projected into eight views. This is an original joint diagram, not final character art or a physical simulation. The lead sole stays planted while the rear heel rises; hips, knees, pelvis, chest, free arm and sword change together.

Run `node motion-proof.mjs` to regenerate joint data and numerical report. Then run `MPLCONFIGDIR=/tmp/mpl-sprite-study XDG_CACHE_HOME=/tmp/sprite-font-cache python plot-motion-proof.py` to generate diagrams/GIF; Python requires Matplotlib and Pillow.

`motion-proof-report.json` covers 401 continuous samples, contact coordinates, reachability, limb lengths, joint ranges and blade ground clearance. These are authored diagnostic values, not measurements of RO or proofs of correct painted animation. The painted v3 rear foot does not exactly retain this guide's rear-toe contact.

`SE-motion-proof.gif` shows the coordinated movement. `eight-directions-motion-proof.png` shows projected joint guides; it does not supply finished painted views. See [repair findings](../../references/full-body-attack-repair.md) for studies, limitations and rejection lessons. Retrieval audits include failed requests; failures are not counted as inspected sources. No third-party artwork is included here.
