# Shared authoring origins and reusable small-motion checks

Read [v49 pickup repair](../../../research/sprite-animation/pickup-contact-v49/README.md), [external evidence](../../../research/sprite-animation/pickup-contact-v49/references/README.md) and [v50 small-motion renderer](../../../research/sprite-animation/grounded-actions-v50/README.md). These supersede the current-status pointer in frozen v46 instructions only for this new work; historical cases and their failures remain unchanged.

1. Separate a wrong drawing from an authoring-grid origin error. v49 switches to all8coherent midpoint drawings from one raw bank and declares2shared row origins calibrated from2cells. Original8keys and timestamps remain exact. Fourteen heldout exposures per shoe pass unchanged6px budgets, with2pxY versus old12/14. This is not a new anatomical foot lock, per-frame fit or permission to normalize every silhouette.
2. Never hide selection changes behind “only registration changed.” v49 replaces the last4midpoints that v48 selected from another native attempt. Keep source hashes, mapping and actual old control. v48 must still fail its unchanged contract.
3. Observe actual pixels with declared support schedules. A blank, split, merged or cut shoe cannot pass because a bounding box or colored rig endpoint says it should. Screen-left/right windows are not inferred anatomical labels. Use a separate case per constant support location; a step to another landing location needs another support interval, not a global no-motion requirement.
4. Use actual external sources and state acquisition status. v49 has256external exposures including repeated APNG/idle states,136actual GLB mesh captures, clocks/bones, pinned files and licenses. A creator page, source pose, invisible joint, repeated exposure and new drawing are different evidence. Old own attacks remain excluded.
5. For small in-view motions, an unchanged original texture and one authored rest-space mesh can avoid drawing-to-drawing identity/boot drift. v50 uses original WebGL code, static bands and actual external curves. Measure dense triangle orientation, rigid-head residuals and rendered sole surfaces. A real injected fold and a second character/resolution are necessary controls. Do not use this method to fake out-of-plane sitting/rotation or call it a finished modular bank.
6. Keep durations/events in one controller. Test large deltas, loop boundaries, silent review seek and cancellation *from inside an event callback*. The latter must stop at the event timestamp and suppress later events even when the update spans the whole clip. Current clock demonstrates events only; it does not authorize game damage/inventory.
7. Compare encoded preview timing as well as metadata. v50 caught670→640ms from GIF quantization and now quantizes the shared exposure boundaries to10ms. Retain the failed encoded GIF. Equal nominal FPS is not equivalent playback; consecutive identical GIF states may merge legally.
8. Browser alpha conversion is not raw RGBA identity. v49 inputs remain unchanged; rendered alpha is exact, alpha≥128 straight RGB differs≤1, and premultiplied RGB differs≤1. Alpha255 assertions alone would be vacuous here because source maxalpha254. Record pixel counts and use actual composited buffers.

Reuse requires per-character rest/contact annotations, not new algorithm code. `reuse-external-adapter.json`, contact-case examples and the scripts are executable templates. No automatic hidden-joint detector, complete-head swaps, all-angle proportions, all-motion physical correctness or universal zero-error claim follows from these bounded passes.
