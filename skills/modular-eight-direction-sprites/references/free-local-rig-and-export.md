# Free local character authoring and source/capture verification

Latest user instruction: no credits, use free methods. Close the paid Tripo proposal. Do not call an asset/image/video generation provider, upload the character, inspect credentials/accounts or infer a new spend approval. Use installed local tools and original authored geometry. [v44 case](../../../research/sprite-animation/free-character-v44/README.md), [detailed procedures](../../../research/sprite-animation/free-character-v44/KNOW-HOW.md).

- A real saved full-character rig is stronger evidence than source points plus terminal mannequin meshes. Bind internal authoring pieces to actual bones; keep runtime ownership as body_outfit/complete_head. Neither internal mesh count nor source success approves artwork or replacement-layer exports.
- Bone matrices do not specify length. Establish nonzero head/tail, intended roll and explicit length, verify actual matrix_local, then evaluate neutral vertices. Keep body authoring coordinates distinct from bone-local axes.
- Normalized vertex groups can survive a removed Armature modifier. Verify the actual enabled intended modifier on every rendered object; deselect unrelated objects before bpy.ops conversions. Reopen the saved file and evaluate motion, including rigid neck/trim/eye/boot accessories.
- Render has a clock: set actual scene frame/subframe and verify real bones after render. Retain static wrong-clock PNGs as negatives. Never let a correct pre-render pose record approve a reset raster.
- Interpolate targets with bounded curves, re-solve fixed-length IK, use one display calibration, and inspect actual depth-tested ownership captures. Green head surface centroid is not an anatomical joint detector. Hidden arbitrary painted anatomy remains unknown.
- Standard glTF skinning may not reproduce Blender DQ; structural inspection and normalized weights can pass while the actual imported surface differs. Reimport and compare actual evaluated geometry at explicit times; check omitted non-armature modifiers too. Any sampled corrective morph solution must disclose its time coverage, between-sample limits and clip synchronization.
- Current local model is a blockout, not the approved hand-painted style. Do not present it as final sprites, factory completion, acting/anatomy approval or game admission. Preserve prior frozen evidence and the accepted W bank. Continue new authoring in a fresh versioned case after publication.
