Original motion, sampling, independent part-image export and opaque-depth reconstruction studies were implemented and tested. The newest painted attack candidate is separately packaged; it covers one facing and separates only the trail. The user's lower-rate request supersedes the earlier high-rate attack experiment. No game files were changed. Final sprite artistry, complete modular coverage and game integration still require validation.

The package can evolve as the user supplies preferred style, replaceable slots, body families, required actions, and examples of correct and incorrect output.
