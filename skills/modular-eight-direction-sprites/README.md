This is a local skill package draft. It has not been registered with the session's skill loader. Original motion, higher-FPS sampling, independent part-image export and opaque-depth reconstruction studies were implemented and tested. No production character assets or game files were changed. Final sprite artistry, production packing and game integration still require validation.

The package can evolve as the user supplies preferred style, replaceable slots, body families, required actions, and examples of correct and incorrect output.
