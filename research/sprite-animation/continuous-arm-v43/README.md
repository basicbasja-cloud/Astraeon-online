# v43 — แก้ข้อมือ, ทดลองผิวแขนจริง และตรวจการสลับแขนข้ามเฟรม

**อนิเมชันภาพวาดยังไม่ผ่านครบ 8 ทิศ** รอบล่าสุดวาดท่าก้มสุดได้ดีขึ้น แต่กลับใช้แขนซ้ายยกของขึ้น ทั้งที่แขนขวาเป็นคนเก็บ จึงยังไม่ใช้เป็นมาตรฐานผลิตจริง

เปิด [เครื่องมือตรวจ 8 มุม](review.html) ในเครื่องเพื่อเล่นต้นแบบ, เปิดกริด/กระดูก และดูภาพวาดท่าก้มเก็บของแต่ละมุมแยกกัน ภาพที่เคลื่อนไหวเป็น **ต้นแบบ 3D**; ภาพวาดด้านล่างยังเป็น **ท่าเดียว** ไม่ใช่ GIF งานภาพ final
