# Ragnarok Online Swordsman — eight-direction reference

This folder contains browser captures of the male and female Swordsman sprite-sheet pages on The Spriters Resource. They are included as visual research references for ASTRAEON ONLINE's original Swordsman work.

Use these captures only to compare high-level presentation: whether directional coverage reads clearly, how different action groups are organized, and whether motion remains legible at sprite scale. Do not trace, copy, or extract the Ragnarok pixels, character designs, proportions, poses, timing, costumes, weapons, or other distinctive artwork. These captures are not ASTRAEON production art, runtime assets, or a license to reuse the material.

ASTRAEON's approved direction order remains **S, SW, W, NW, N, NE, E, SE**. Keep its layered painted character art and production pipeline original.
