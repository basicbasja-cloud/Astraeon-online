## Use

## What is supported
Fountain plaza, cobbled main roads and junctions, timber-frame plaster houses, orange/red tiled roofs, shop awnings, planted strips and benches, cathedral facade and forecourt, practice courts, walls, gate passages and bridge views.

## Layout limits
This clip does not provide a clean complete city map or an unobstructed full castle view. The blue roof at the bridge must not be treated as proof of a castle. Gate compass directions and global building coordinates are not established. Use the mini-map only as partial context; do not claim a complete accurate plan from these frames. No reconstructed city plan is included.
