# Native surface-paint checkpoint

Internal NO-SHIP experiment. The approved concept is unchanged. This checkpoint
does not match its finished quality and is not offered as an accepted character.

`surface-painted-source.blend` contains real hair, costume, glove and weapon
surfaces with fixed rest UVs and painted material textures. It renders eight
actual headings at one camera, scale, 320 canvas and root (160,264). `painted-source.blend`
is the structural source before the separate detail/coat stages. Run the build,
detail, coat and bake-check scripts through Blender MCP in that order.

The original concept supplies design authority. The built-in imagegen tool supplied
only the material swatch atlas used by the final coat. The final prompt is
`paint/MATERIAL_PROMPT.txt`; no API key or paid provider was used. A four-view
paint sheet changed the fixed guide poses/layout and was rejected in
`paint/rejected-registration-01/`. The portrait-projection blend and its renders
are an earlier diagnostic experiment, not the final surface-painted source.

The SE visible-only module renders demonstrate one equipped composition. Removal
frames re-render actual hidden surfaces; they are not an arbitrary-swapping export.
W/NW/N full-character and isolated grip diagnostics use matching frames.

There are no armatures, weights or actions in this source scene. Its voxel body
is not deformation topology; the two-component topology and art shortcomings
prevent rigging handoff. Professional free bases are being inspected separately
after the owner's asset-download authorization. No runtime package is admitted.
