# Coherent Archer masters, before semantic cutouts

Latest complete-body candidate for BasicAttack: both sexes, four diagonal
cameras, sixteen source poses. All 128 images retain the same whole-body paint
workflow and the original tall Swordsman style authority.

These are not yet registered to the final runtime canvas or admitted as a
playable character. Intermediate pose agreement, naturalness, hand/bow fit,
all semantic part boundaries, hidden surfaces and swaps remain open.

`plan-source.json` and `repair-source.py` reproduce the complete-master recovery
correction from pinned local corrective paint sources. All 66 source bone
matrices match first/recovery poses before reuse. Only the explicitly bounded
projectile corridor may use corrected paint; every other first-pose pixel stays
unchanged at recovery. Frames 0–14 are preserved from the reviewed cleaned input.

`protected-pixel-proof.json` covers all eight groups. `preview-recipe.json`
feeds `render_fixed_master_review.py` without per-frame fitting. The normal/slow
GIFs repeat a one-shot for review; sample timing and the inspection hold are not
final gameplay timing or smoothness acceptance.

Cut parts from these corrected complete masters. Do not append older SE head or
body cutouts whose source pixels no longer match the current matte. Reuse is
allowed only with matching pose, camera, body fit and actual source pixels.
