# Retired character previews — do not use

The three `swordsman-male-v3*` folders here are retired small, development-only runtime previews. They were moved here at the owner's request so they cannot be selected as the character to evaluate. Their files are kept unchanged for historical evidence; the JSON atlas paths still refer to their old runtime locations and these folders are not playable packages.

The required visual baseline remains the original taller four-direction Swordsman, including its unchanged masters, cutouts and effects under `paint-jobs/swordsman-master-cutout-v2/prototypes/basicattack-mesh2motion-reset/`. Motion-source and Blender guide assets are retained. This move does not certify the baseline's animation, fix frame or size drift, or complete any patch character.

Retired development URLs are explicitly rejected. Legacy writers require explicit new candidate IDs and reject the retired IDs so a normal invocation cannot recreate the removed previews. New production art must meet the master, motion, cutout, size and gameplay gates in the patch goal.
