# Original Wayfarer runtime materials

`wayfarer-materials-v1.png` is original generated ASTRAEON material artwork:
cream masonry, blue civic roof tiles, copper/clay roof tiles and warm plaster.
`wayfarer-nature-v1.png` is original generated ASTRAEON artwork: grass, garden
soil, broadleaf foliage and turquoise water. Each source is a 2×2 atlas; the
Blender material nodes and exported material catalog register the quadrant.
Sources were generated for this project on 2026-10-01 and remain intact.
Runtime WebP files are compressed copies. The browser creates separate tile mip
chains to avoid bleeding between neighboring atlas quadrants. No Ragnarok
textures or other proprietary game material is included.

`assets/town-limestone-v1.webp` remains the project's existing original paving.
Author UVs in Blender; the exporter preserves face-corner UVs and transforms.
